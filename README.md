# soundscapes
a repo that explores visualizations of sound

## Aspects

`assets` - contains stuff (like media files, data) that you can plug into tools and experiments
`components` - contains pieces of code that can be plugged into tools and experiments
`experiments` - contains implementations of different ideas - in the form of applications, webpages, pieces of digital art, nft collections, songs, etc
`libraries` - contains libraries of code that can be utilized by components, tools, and experiments
`templates`- contains reproduceable full setups for either `experiments` or `tools` to speed the process iterating
`tools` - contains larger structures that use assets, components, libraries - to either learn or build more complex structures
